# Une question pour toi

Page web personnelle et interactive qui pose une question (« Veux-tu aller en date avec moi ? ») avec une animation à la réponse.

## Contenu

- `index.html` : page unique (HTML, CSS et JavaScript intégrés), polices Google Fonts.
- **Espace administrateur** intégré pour personnaliser la demande (texte, prénom). Les réglages sont enregistrés dans le navigateur (`localStorage`), sans serveur.

## Lancer

Ouvrir `index.html` dans un navigateur, ou le publier tel quel (GitHub Pages, Netlify…).
